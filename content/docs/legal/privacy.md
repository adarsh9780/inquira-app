# Privacy Policy

Last updated: June 7, 2026

## Our Privacy Commitment

Inquira is designed with privacy as a core principle. Workspace data is stored and processed locally
by default. Data may leave your computer when you choose cloud-based AI services or when locally
executed Python or terminal commands use network access.

## Data Collection

### Local-Only Processing

When you use Inquira with local AI models (like Ollama):
- All data processing happens on your machine
- Inquira does not intentionally send prompts or workspace data to an AI provider
- Your datasets remain entirely under your control

Local Python and terminal execution is not sandboxed and runs with your operating-system user
permissions. Executed code can access and transmit data if it uses network access.

### Optional Cloud Services

If you choose to use cloud AI providers (OpenAI, Anthropic, etc.):
- Queries are sent to the provider you select
- Each provider has their own privacy policy
- You can disable cloud AI at any time

### Usage Analytics

We collect minimal, anonymized usage data to improve the product:
- Feature usage statistics (what features are used)
- Error reports (without personal information)
- Performance metrics

**We do not collect:**
- Your datasets or query content
- Personal identification information
- Your files or file names

## Data Storage

All workspace data is stored locally:
- DuckDB databases in your app data directory
- Chat history and analysis artifacts
- User preferences and settings

## Your Rights

You can:
- Delete all local data at any time
- Export your workspace data
- Opt out of usage analytics

## Updates

We will notify users of material changes to this privacy policy through the app.

## Contact

For privacy concerns, contact: privacy@inquiraai.com
