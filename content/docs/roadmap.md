# Roadmap

Here's what we're working on for future releases.

## In Progress

### Q2 2026

- [ ] **Multi-file Analysis**: Support for analyzing data across multiple related files
- [ ] **Improved Chart Theming**: More visualization options for Pro users
- [ ] **Performance Improvements**: Faster cold start times and query execution

### Q3 2026

- [ ] **RAG Integration** (Pro): Bring your own knowledge base for context-aware analysis
- [ ] **Multiple Workspaces** (Pro): Better organization for different projects
- [ ] **Plugin System**: Extensible architecture for custom data sources

## Future Ideas

### Community Requested
- Direct database connectors (PostgreSQL, MySQL)
- API data source integration
- Scheduled analysis tasks
- Collaborative features for teams

### Enterprise Features
- LDAP/SSO integration
- Audit logging
- Centralized workspace management
- Custom data connectors

## Completed

- [x] Local DuckDB integration
- [x] Natural language query interface
- [x] Code editor with autocomplete
- [x] Interactive Plotly charts
- [x] macOS and Windows desktop builds
- [x] Persistent workspaces
