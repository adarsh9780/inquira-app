# System Architecture

Inquira is built as a desktop application using a modern tech stack that prioritizes privacy, performance, and user control.

## Tech Stack

- **Frontend**: Vue.js with Nuxt
- **Backend**: Python (FastAPI)
- **Desktop**: Tauri (Rust)
- **Database**: DuckDB (local, embedded)
- **AI**: LangGraph for agent workflows, with support for OpenAI, Anthropic, OpenRouter, and Ollama

## Core Components

### Desktop Shell
The Tauri-based desktop application provides:
- Native window management
- Local file system access
- Local Python and terminal execution

### Python Backend
A FastAPI server handles:
- LangGraph agent orchestration
- Jupyter kernel management for Python execution
- DuckDB query processing

### AI Agent Workflow
The AI agent uses LangGraph to:
1. Parse natural language queries
2. Generate Python analysis code
3. Execute code in a local Jupyter environment with the desktop user's operating-system permissions
4. Return results, charts, and natural language explanations

## Local Execution Security

Python generated by the AI, Python run from the editor, and terminal commands execute locally with
your operating-system user permissions. They are not sandboxed and may access files, processes,
network resources, environment information, and memory available to your user account.

Inquira applies prompts, policy checks, timeouts, and output bounds to reduce some risks, but these
controls are not a security boundary. Review code before running it and maintain backups of
important data.

## Privacy Model

All data processing happens locally on your machine:

```
┌─────────────────────────────────────────────────────────┐
│                    Your Computer                          │
│  ┌─────────────┐    ┌─────────────┐    ┌────────────┐ │
│  │  Your Data  │───▶│   DuckDB    │───▶│  Results   │ │
│  │   (CSV,     │    │   (Local)   │    │  & Charts  │ │
│  │   Excel)    │    │             │    │            │ │
│  └─────────────┘    └─────────────┘    └────────────┘ │
│                          ▲                             │
│                          │                             │
│  ┌─────────────┐         │         ┌───────────────┐  │
│  │  AI Agent   │─────────┴────────▶│    Local      │  │
│  │  (LangGraph)│                     │   Python     │  │
│  └─────────────┘                     │   Execution   │  │
│                                      └───────────────┘  │
└─────────────────────────────────────────────────────────┘
```

Workspace data is stored locally by default. Cloud AI providers receive the prompts and context you
choose to send. Because local execution has your user permissions, executed code can also transmit
data if it uses network access.

## Editions

Inquira comes in three editions:

- **Community Edition (CE)**: Free, local-only
- **Pro**: Adds RAG support and multiple workspaces
- **Enterprise**: Adds data connectors and MCP support
